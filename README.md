# 🐍 Curso de Python do Zero

Bem-vindo ao **Curso de Python do Zero**! Este material foi projetado especificamente para pessoas que possuem **nenhum ou pouco conhecimento em programação**.

O objetivo deste repositório é servir como guia completo de estudo e suporte para as aulas práticas utilizando o **VS Code** como ambiente de desenvolvimento.

## 🎯 Objetivo do Curso

Aprender a programar em Python de forma simples, direta e prática, construindo uma base sólida para resolver problemas reais e desenvolver seus próprios projetos.

## 📅 Cronograma do Curso

| Módulo | Tema Principal | Descrição Curta | 
 | ----- | ----- | ----- | 
| **Módulo 1** | Introdução & Configuração | Instalação do Python, VS Code e o clássico "Hello World". | 
| **Módulo 2** | Variáveis e Tipos de Dados | Entender `str`, `int`, `float`, `bool` e entrada de dados (`input`). | 
| **Módulo 3** | Tipos de Operadores | Matemática, comparações e lógica. | 
| **Módulo 4** | Estruturas Condicionais | Tomada de decisão com `if`, `elif` e `else`. | 
| **Módulo 5** | Estruturas de Repetição | Laços de repetição com `while` e `for`. | 
| **Módulo 6** | Estruturas de Dados | Coleções de dados usando `listas`, `tuplas` e `dicionários`. | 
| **Módulo 7** | Funções | Organização e reuso de código com `def`. | 

## 💻 Ferramentas Utilizadas

1. [**VS Code**](https://code.visualstudio.com/?utm_source=gemini) - Editor de código (IDE) principal onde faremos toda a escrita e execução de scripts.

2. **Python 3.x** - Linguagem de programação instalada via linha de comando no terminal do VS Code.

   ### 📍 Como abrir o terminal no VS Code:
   * **Opção 1 (Menu Superior):** Clique em `Terminal` > `Novo Terminal` (ou `New Terminal`).
   * **Opção 2 (Atalho de Teclado):** 
     * Windows/Linux: `Ctrl + '` (ou `Ctrl + Shift + '`)
     * macOS: `Cmd + '`

   ### 📥 Comando para instalar o Python via Terminal:
   Escolha o comando correspondente ao seu sistema operacional e execute no terminal do VS Code:

   * **Windows (via Winget):**
     ```bash
     winget install Python.Python.3.12
     ```
   * **macOS (via Homebrew):**
     ```bash
     brew install python
     ```
   * **Linux (Ubuntu/Debian via APT):**
     ```bash
     sudo apt update && sudo apt install python3 -y
     ```

   > **Verificação:** Após concluir a instalação, feche o terminal do VS Code, abra um novo e digite `python --version` (ou `python3 --version`) para confirmar se a versão do Python é exibida.

3. [**Git & GitHub**](https://github.com/?utm_source=gemini) - Controle de versão e hospedagem do código-fonte.
